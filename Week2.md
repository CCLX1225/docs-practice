# Quick Start Guide: Creating a Private Repository on GitHub.com

**Platform:** Desktop browser, English interface
**Audience:** A first-time GitHub user who is already signed in
**Task:** Create a private repository with a README

## Prerequisites

- A GitHub account with permission to create repositories
- A desktop browser signed in to GitHub.com

## Steps

1. Open the **+** menu at the top-right of GitHub.com and select **New repository**.
2. Enter the name `docs-practice` in your own account.
3. Choose **Private** as the visibility.
4. Select the option to **Add a README** file.
5. Select **Create repository**.

## Result check

The new repository page opens and displays the README file. If the name is unavailable, choose another name (for example, `docs-practice-2026`) and try again.
